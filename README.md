# 하나 로컬 버튜버

Qwen3 + Ollama + Piper로 동작하는 저지연 음성·화면 대화 프로그램이야. 캐릭터는 대한민국 모에화 버튜버 하나야.

## 처음 한 번

`setup_hana.bat`을 더블클릭해. Qwen 모델과 한국어 Piper 음성을 내려받아.

Piper는 하나 프로세스 안에서 직접 실행돼. 별도 음성 서버나 `D:` 드라이브 매핑은 사용하지 않아.

그 다음 `start_hana.vbs`를 더블클릭하면 돼. 콘솔 창 없이 `dist\Hana\Hana.exe`를 실행하고, EXE가 없으면 Python GUI로 넘어가. 기존 `start_hana.bat`도 이 숨김 실행기를 호출해.

## GUI

마이크와 화면 관찰은 GUI 시작 시 기본으로 켜져. 하나가 말할 때는 자기 음성을 다시 듣지 않도록 마이크가 잠깐 멈춰.

아래 버튼으로 마이크, 화면 관찰, 음성을 각각 켜고 끌 수 있어. 텍스트 입력창은 보조 수단이고, 기본 대화 방식은 계속 듣는 마이크야.

방송을 켤 때마다 `data/sessions/session_날짜_시간_프로세스번호.jsonl` 파일이 새로 만들어져서 그 방송의 대화만 담아. 장기 기억은 `data/memory.json`에 따로 저장되고, 8번 대화마다 오래된 내용을 짧게 요약해 기억에 보태.

캐릭터와 관계 설정은 `hana_prompt.txt`, 속도와 모델은 `config.json`에서 바꿀 수 있어. 화면 관찰은 `qwen3-vl:4b`, 음성 인식은 `faster-whisper`를 사용해. 하나는 사람 입력을 기다리지 않고 화면을 주기적으로 읽어 먼저 방송 멘트를 하고, 화면 질문에는 최신 고해상도 캡처를 다시 확인해. 화면 모델은 내부 추론 때문에 실제 판독까지 약 10초 안팎 걸릴 수 있어.

EXE는 `build_hana.ps1`을 실행하면 `dist\Hana\Hana.exe`로 만들어져. `start_hana.bat`은 EXE가 있으면 EXE를 실행하고, 없으면 GUI Python 실행으로 넘어가.

기본 모델은 최신 발화의 의미와 캐릭터 맥락을 함께 읽도록 `qwen3:8b`로 맞춰뒀어. 답변은 정해진 문장을 고르는 방식이 아니라 매번 Ollama 모델이 현재 대화에서 새로 생성해. 속도가 더 중요하면 `config.json`을 더 작은 Qwen 모델로 바꿀 수 있지만, 캐릭터성과 문맥 유지력은 떨어질 수 있어.
