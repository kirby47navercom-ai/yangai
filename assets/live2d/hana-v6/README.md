# 하나: 얼굴·옆머리·넥타이 경계 수정 시안

## 현재 확인 대상

현재 전신 후보는 **`hana-refined-4k.png`**입니다. 규격은 **4096 × 6144 RGBA PNG**입니다. 이전 V5의 확대본을 바탕으로, 내장 이미지 생성 도구로 별도 제작한 얼굴·옆머리 및 넥타이 세부 원화를 정렬하여 적용하였습니다. 전신 전체를 해당 해상도로 원생성한 파일은 아닙니다.

이번 작업의 목적은 볼과 머리카락 사이의 불명확한 경계, 눈·입 주변의 불필요한 선, 안쪽 옷과 넥타이의 흐린 색 구분을 개선하는 것입니다. 머리카락은 큰 다발 중심으로 정리하고, 부드러운 곡선과 명확한 외곽선, 셀 셰이딩 및 제한적인 소프트 셰이딩을 사용하도록 요청하였습니다. 노이즈·모아레·그레인·반짝이·파티클·블룸은 생성 지시에서 제외하였습니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `hana-refined-4k.png` | 현재 검토용 전신 투명 PNG입니다. |
| `face-detail.png` | 별도로 생성한 1254 × 1254 얼굴·옆머리 상세 원화입니다. 얼굴과 머리 다발의 형태 확인에 사용합니다. |
| `chest-detail.png` | 별도로 생성한 1254 × 1254 가슴 상세 원화입니다. 전체 그림을 그대로 합성하지 않고 중앙 넥타이 주변만 사용합니다. |
| `PROMPT-face-detail.txt` | 얼굴·옆머리 상세 원화에 실제 사용한 생성 지시문입니다. |
| `PROMPT-chest-detail.txt` | 넥타이 상세 원화에 실제 사용한 생성 지시문입니다. |
| `qa/*-edit-input.png` | 상세 원화를 생성할 때 사용한 입력 영역입니다. |
| `qa/face-before-100pct.png`, `qa/face-after-100pct.png` | 수정 전후 얼굴을 동일 좌표에서 잘라낸 실제 픽셀 크기 검수본입니다. |
| `qa/chest-before-100pct.png`, `qa/chest-after-100pct.png` | 수정 전후 넥타이를 동일 좌표에서 잘라낸 실제 픽셀 크기 검수본입니다. |
| `qa/face-seams-100pct.png` | 얼굴·목·망토 경계까지 포함한 실제 픽셀 크기 검수본입니다. |
| `qa/refined-*.png` | 밝은색·어두운색·청색 배경에 합성한 축소 미리보기입니다. |
| `qa/detail-report.json` | 수정 좌표, 변경 픽셀 수 및 자동 검사 결과입니다. |

## 적용 방식과 검사

얼굴 상세 원화는 1024 × 1024로 축소하여 필요한 영역을 사용하였습니다. 넥타이 상세 원화는 704 × 704로 축소한 뒤 중앙의 필요한 부분만 적용하였습니다. 상세 원화를 저해상도 전신 크기로 축소한 후 다시 확대하는 방식은 사용하지 않았습니다.

얼굴·머리카락 영역은 상세 원화의 투명도를 사용합니다. 넥타이는 실제로 불투명한 천이므로 원래 전신 이미지의 알파를 유지합니다. 생성된 가슴 상세 원화 전체를 적용하면 일부 흰 옷이 반투명해지는 문제가 있어 해당 방식은 제외하였습니다.

자동 검사는 다음 항목을 확인합니다.

- 출력 크기와 RGBA 형식
- 지정한 수정 범위 밖의 변경 픽셀 수가 0인지 여부
- 넥타이 적용 영역의 알파가 원본과 동일한지 여부
- PNG 저장 후 다시 읽은 RGBA 값이 저장 전 값과 동일한지 여부

얼굴·옆머리·넥타이·목 주변을 확대하여 육안 검토하였습니다. 검수에서 확인된 직사각형 이음새와 목 주변 중복 윤곽을 줄이기 위해 적용 범위를 조정하였습니다. 초기 합성본과 세부 표현이 다시 약해진 전신 재생성본은 최종 후보에서 제외하고 로컬의 무시된 `.local-tools/live2d/rejected/` 아래에 보관하였습니다. 원본 자료는 삭제하지 않았습니다.

## 남아 있는 한계

이 파일은 사용자 확인 전의 **평면 원화 시안**입니다. 파츠 분리 PSD, 가려진 부분의 복원 원화 또는 리깅 완료 모델이 아닙니다. 생성 결과가 모든 장식과 겹침 구조를 정확히 보존한다는 보장도 없습니다. 정밀 파츠 제작 단계에서는 각 머리 다발의 뿌리, 겹침 뒤의 피부·옷 및 이동 시 드러나는 부분을 별도로 그려야 합니다.

확대본이므로 무제한 확대에서도 원생성 고해상도 원화와 같은 품질을 보장하지 않습니다. 전체 이미지의 모든 미세 질감이 사라졌음을 자동으로 증명한 것은 아니며, 해당 여부는 제공된 실제 픽셀 검수본과 함께 판단해야 합니다. 생성 원본의 알파는 일부 내부 영역에서도 정확한 255가 아닌 값이 포함될 수 있습니다.

## 재현

기존 Node.js와 `sharp`를 사용할 수 있는 환경에서 프로젝트 루트를 기준으로 실행합니다. 새로운 의존성은 추가하지 않았습니다.

```powershell
node tools/live2d/compose-detail.cjs
```

합성 좌표는 현재 원화에만 맞추어져 있습니다. 다른 포즈나 다른 비율의 그림에는 좌표를 다시 확인해야 합니다. TTS·음성 파일, 앱 실행 코드 및 기억 데이터는 이번 작업에 포함하지 않았습니다.
