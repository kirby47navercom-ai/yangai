# 하나: 선화·색면 정리 및 투명 배경 재생성 시안

## 현재 판정

이 폴더에는 사용자의 수정 요청에 따라 **참고 디자인을 바탕으로 새 그림 생성을 요청한 결과**를 보관합니다. 기존 회색 배경 원화에서 픽셀을 지우거나 분리 마스크를 적용한 결과가 아닙니다. 생성된 알파 채널을 그대로 유지하였습니다.

현재 결과는 디자인 확인용 평면 PNG입니다. 선화·채색이 개별 레이어로 작성된 작업용 PSD, 정밀 파츠 PSD 또는 리깅 가능한 완성 모델이 아닙니다. 생성 요청에서 선화와 색면의 정돈을 강조하였으나, 실제 선화·채색 레이어 파일이 제공된 것은 아닙니다. 최종 디자인 승인도 아직 받지 않았습니다.

## 파일

| 파일 | 실제 규격 및 용도 |
| --- | --- |
| `hana-clean-native.png` | 생성 도구가 반환한 1024 × 1536 RGBA PNG. 바이트 단위 복사본이며 배경 제거·침식·알파 임계값 처리를 추가하지 않았습니다. |
| `hana-clean-4x.png` | 로컬 Real-ESRGAN으로 색상 정보를 확대하고 원래 알파를 보간한 4096 × 6144 RGBA 작업 후보입니다. 처음부터 해당 해상도로 그려진 원본은 아닙니다. |
| `reference-tail.png` | 두껍고 부드러운 꼬리의 형태 참고 이미지입니다. 배경이 포함된 참고본이며 최종 투명 원화가 아닙니다. |
| `PROMPT.txt` | 마지막 새 그림 생성에 사용한 실제 지시문입니다. 내장 이미지 생성 도구를 사용하였고 CLI/API 대체 방식은 사용하지 않았습니다. |
| `qa/report.json` | 원본 PNG의 실제 해상도, 알파 분포, 캔버스 경계 접촉 검사 기록입니다. |
| `qa/checkerboard-preview.png` | 실제 알파를 격자 배경 위에 합성한 검수용 이미지입니다. 이 미리보기 자체는 투명 PNG가 아닙니다. |
| `qa/preview-*.png` | 밝은색·어두운색·청색 배경에 합성한 검수용 이미지입니다. |
| `qa/*-4x.png` | 확대본의 얼굴·소매 및 허리·꼬리 일부를 실제 픽셀 크기로 잘라 확인한 검수 이미지입니다. |

## 이번 수정의 기준

1. 원래 의상의 적청색 천, 치마 패널과 테두리, 자수, 소매 배색, 장식 구조를 유지하도록 요청하였습니다. 색이 있다는 이유로 장식으로 분류하거나 삭제하지 않습니다.
2. 잔선과 거친 채색 질감을 줄이고, 매끄러운 윤곽선·구분되는 색면·넓고 부드러운 음영을 사용하도록 요청하였습니다. 머리와 꼬리는 의미 있는 다발 위주로 정리합니다.
3. 꼬리는 흰색 몸통과 검은 말단 하나로 구성하며, 두꺼운 볼륨과 연속된 곡선을 유지하도록 요청하였습니다. 잘려 나간 듯한 홈이 있는 기존 분리본을 참고하지 않았습니다.
4. 머리카락 사이, 소매와 허리 사이, 손가락·다리 사이와 꼬리 안쪽의 빈 공간은 투명하게 처리하도록 요청하였습니다. 옷 안감은 배경과 구분합니다.

## 확인한 내용과 남아 있는 한계

생성 원본의 실제 알파 채널과 여러 배경 위의 합성 결과를 확인하였습니다. 머리·허리 사이 틈 및 꼬리 윤곽, 확대본의 얼굴·옷·털 표현을 육안 검토하였습니다. 원본의 불투명한 내용물이 캔버스 가장자리에서 잘리는 경우는 이번 검사에서 발견되지 않았습니다.

다만 생성 파일의 캐릭터 내부 알파는 주로 250~254이며 정확한 255로 고정되어 있지 않습니다. 이 값은 임의로 보정하지 않았습니다. 배경이 투명하다는 검사와 모든 파츠 경계가 제작용으로 확정되었다는 판정은 다릅니다. 가는 가장자리와 작은 장식은 후속 원화 정리에서 추가 검수가 필요합니다.

재생성 결과이므로 원화와 픽셀이 일치하지 않으며, 작은 장식이나 선의 모양은 달라질 수 있습니다. 고해상도 후보 역시 AI 확대본입니다. 정밀 선화 및 파츠 제작이 모두 완료되었다고 판정하지 않습니다.

## 중단한 작업

이전 배경 제거 시도에서 회색 잔여 배경, 머리·손가락 일부의 불필요한 투명화, 꼬리 윤곽 손상이 확인되었습니다. 의상 보완 후보에서는 배색이 사라지는 문제도 발생하였습니다. 해당 결과와 대략적인 분리 마스크/PSD는 **미채택 작업 자료로 격리**하였고, 이 시안의 파츠 원본으로 사용하지 않습니다. 자료는 삭제하지 않았으며 로컬 `.local-tools/live2d/rejected/`에 보관합니다. 이 경로는 Git에서 제외됩니다.

기존 애플리케이션, TTS·음성 파일, 기억 데이터, 계정 설정은 변경하지 않았습니다. 기존 승인본은 `../hana-v1/`에 그대로 보존합니다.

## 검수 및 확대 재현

작업 도구는 `tools/live2d/review-transparent.cjs`와 `tools/live2d/upscale-transparent.cjs`입니다. Node.js 및 `sharp`가 필요하며, 확대 도구는 기존 `.local-tools/realesrgan-20220424/`에 설치된 실행 파일과 모델을 사용합니다. 저장소에는 도구 바이너리와 모델을 포함하지 않습니다.

검수 스크립트는 입력 PNG를 수정하지 않습니다. 확대 스크립트는 RGB에 `realesrgan-x4plus`를 적용하고 기존 알파 채널을 같은 크기로 보간합니다. 배경 분리 모델로 알파를 다시 추정하지 않으며, 저장한 알파와 보간 결과가 동일한지 검사합니다. 로컬 확대 단계에서는 이미지를 외부 서버로 전송하지 않습니다. 앞선 내장 이미지 생성 호출은 별도의 처리입니다.

프로젝트 루트에서 의존성을 사용할 수 있는 환경으로 다음 명령을 실행합니다.

```powershell
node tools/live2d/review-transparent.cjs assets/live2d/hana-v4/hana-clean-native.png
node tools/live2d/upscale-transparent.cjs
```
