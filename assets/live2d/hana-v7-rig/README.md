# 하나 전신 파츠 및 Umamo 초기 리그

이 디렉터리는 기존 4096 × 6144 원화에서 분리한 전신 파츠와, 무료 편집기 Umamo로 작성한 초기 회전 리그를 보관합니다. 원본 원화와 기존 버전의 파츠는 변경하지 않습니다.

## 파일

- `parts/`: 원래 해상도와 위치를 유지한 전신 파츠 PNG 191개입니다. 의상 색상은 장식으로 취급하여 제거하지 않습니다.
- `hana-rig-source.psd`: 전신 파츠와 비활성 눈 작업용 마스터를 포함한 215레이어 PSD입니다. 눈 마스터 24개는 아직 최종 시선·눈 깜박임 리그에 사용되지 않습니다.
- `umamo/hana.cmo3`: Umamo에서 편집할 수 있는 실제 모델 파일입니다. PNG 미리보기나 관절 JSON만으로 리깅 완료를 표시하지 않습니다.
- `umamo/hana.moc3`, `hana.model3.json`, `hana.cdi3.json`, `hana-textures/`: 실행용 내보내기 묶음입니다. 모델과 텍스처 파일을 함께 보관해야 합니다.
- `rig.json`: 관절 위치·부모 관계·파츠 연결 정의입니다.
- `preview.html`: PNG 기반 관절 미리보기입니다. 네이티브 모델의 렌더링을 대신하는 검증 자료는 아닙니다.
- `qa/umamo-rig.json`: 실제 모델을 생성하고 다시 읽어 수행한 검사 결과입니다.
- `qa/skeleton.png`, `qa/contact-*.png`: 전신 관절 배치 및 개별 파츠 확인 이미지입니다.
- `qa/psd-composite.png`, `qa/review-*.png`: 저장한 PSD의 실제 레이어 순서로 다시 합성한 전신 및 7개 구역의 확대 검토 이미지입니다.
- `qa/pose-*.png`: 머리·양팔·양다리·머리카락·의상·꼬리의 6종 PNG 회전 검사입니다. 네이티브 렌더링이나 모든 동작의 완성도 검사가 아닙니다.
- `underpaint/`: 가려진 작은 피부·원단 영역의 색상 보완에 사용한 생성 밑그림입니다. 캐릭터 전체 원화로 교체하지 않습니다.

## 현재 리깅 범위

머리, 몸통, 양팔·팔꿈치·손목·손, 양다리·무릎·발목, 양쪽 묶음 머리, 개별 머리카락, 치마·재킷·망토, 리본·넥타이·매달린 장식, 꼬리 4구간에 회전 계층을 구성했습니다. 전체 65개 회전 변형기에 기본·음수·양수 3개 자세를 설정했습니다. 모든 전신 파츠는 관절 계층에 연결되어 있습니다.

초기 리그용 메시는 사각형 1장에 머무르지 않고 규칙 격자로 세분화했습니다. 다만 최종 표정·관절 변형에 맞춘 수작업 윤곽 메시 또는 고급 워프 리그는 아닙니다. 움직임 범위는 작은 각도로 제한합니다.

## 원화 보존과 보완

원본 원화 파일을 변경하지 않으며, 얼굴 피부 밑그림을 제외한 190개 파츠의 원래 소유 픽셀을 보존합니다. 투명 경계에 남아 있던 넓은 배경 번짐은 알파 채널만 정리하고, 원래 해상도에서 좁은 안티앨리어싱 경계를 유지합니다. 장식 아래의 작은 빈 영역은 주변 재질을 이용하여 보완합니다. 관절 접합부에는 인접한 원화의 겹침 여유를 추가합니다.

전신 PSD를 저장할 때 그룹과 파츠 순서를 모두 뒤집던 오류를 수정했습니다. 해당 오류로 인해 얼굴 피부가 눈·입 위에, 의상 밑그림이 장식 위에 표시되었습니다. PNG 합성만 확인하는 대신 저장된 PSD를 다시 읽어 실제 표시 순서로 합성하고 검사합니다. 네이티브 CMO3/MOC3의 표시 순서도 PSD와 비교합니다.

피부와 원단에는 이미지 생성 도구의 보완 밑그림을 적용했습니다. 기존 마스크의 구멍과 피부 접합선이 남지 않도록 `Face` 피부 밑그림은 연속된 채색과 투명 경계로 교체했습니다. 눈·눈썹·코·입·머리카락의 개별 원화 파츠는 변경하지 않습니다. 원단은 기존 의상색과 재질이 일치하는 숨은 영역에만 적용합니다. 생성 전신 이미지의 전체 윤곽이나 알파 채널로 원화를 교체하지 않습니다. 얼굴 피부를 제외한 190개 파츠의 원래 소유 픽셀은 자동으로 일치를 검사합니다.

이 보완은 완전히 가려진 신체·머리카락·의상 전체를 새로 그린 작업이 아닙니다. 큰 동작에서 나타나는 가려진 면, 머리카락의 일부 조각 경계, 장식을 옮겼을 때 드러나는 보완 영역은 추가 재작화 및 육안 검토가 필요합니다.

이번 전신 육안 검사에서는 191개 전체 파츠 목록, 얼굴·가슴·허리·양팔·다리와 부츠·꼬리의 7개 구역, 6종 회전 미리보기를 확인했습니다. 남은 문제는 소매 접합부와 안쪽의 작은 조각, 일부 머리카락의 흩어진 조각, 꼬리 동작에서 떨어져 보이는 작은 경계 조각입니다. 해당 항목을 완성한 것으로 표시하지 않습니다.

## 검증과 미완성 항목

자동 검사는 파츠 PNG→PSD 픽셀·좌표 보존, PSD 실제 겹침 순서 및 재합성, 관절 계층의 중복·순환, 중립 자세 좌표, CMO3 저장 후 관절·파츠 개수, 68개 자세의 CMO3/MOC3 저장 전후 좌표 일치와 MOC3 디코딩을 확인합니다. 68개 자세는 기본 자세·머리·꼬리 및 65개 파라미터 각각의 양수 끝점입니다. 좌표 일치는 저장 호환성 검사이며 동작의 자연스러움을 보증하지 않습니다. 검사 실패 시 성공한 모델로 보고하지 않습니다.

Umamo 편집기에서 수정된 실제 CMO3 파일을 다시 열어 전신 중립 자세, 확대된 얼굴·의상 표시, 머리 회전 및 최종 모델의 팔 회전·기본값 복귀를 확인했습니다. 검토 파일의 SHA-256을 `qa/umamo-rig.json`에 기록합니다. 머리 회전은 최종 피부 교체 이전 파일에서도 확인했으며 자동 좌표 검사는 최종 파일에 대해 수행했습니다. 이 확인은 초기 모델의 열기·표시·관절 동작에 한정되며, 모든 파츠의 재작화 품질이나 전체 애니메이션의 완성도를 보증하지 않습니다. 재생성하면 수동 편집기 확인 표시는 다시 미확인 상태로 기록됩니다.

이 V7 파일의 눈 깜박임, 홍채의 클리핑과 시선 이동, 입 모양·립싱크, 표정, 호흡, 머리카락·꼬리·장식 물리 설정, 정교한 XYZ 얼굴 회전은 완료하지 않았습니다. 이번 실행용 MOC3는 이전 자체 디코딩 검사만으로 확인하지 않고 Cubism 3.0 대상으로 다시 내보냈으며, Live2D Core 일관성 검사와 중립 모델의 실제 표시를 확인했습니다. 모든 동작과 원화 품질을 확인한 것은 아닙니다. VTube Studio 호환은 별도 검사 대상입니다. 표정·마우스 시선·음량 립싱크를 연결한 후속 [V8 동작 초안](../hana-v8-live/README.md)은 별도 폴더에 보관합니다. 두 모델 모두 완성된 방송 원화·리그로 표시하지 않습니다.

## 열기

프로젝트의 `.local-tools/live2d/umamo-portable/umamo/umamo.exe`를 실행하고 `File` → `Import CMO3` 또는 `Ctrl+O`에서 이 디렉터리의 `umamo/hana.cmo3`를 선택합니다. 라이선스 결제나 Cubism 평가판은 필요하지 않습니다. Umamo 실행 인수로 파일 이름을 넘기는 방식은 해당 배포판에서 파일을 열지 않으므로 사용하지 않습니다.

재생성 시 저장한 모델을 덮어쓰므로, 편집기로 추가 수정한 모델은 반드시 다른 이름으로 보관하십시오. 프로젝트 루트에서 `python tools/live2d/prepare-rig-parts.py`, Node의 기존 이미지·PSD 의존성을 연결한 뒤 `node tools/live2d/build-rig.cjs`, `powershell -NoProfile -File tools/live2d/build-umamo.ps1` 순서로 실행합니다. Python에는 OpenCV와 NumPy, Node에는 sharp·ag-psd·@napi-rs/canvas, Java에는 21 이상과 로컬 Kotlin 컴파일러가 필요합니다. 다운로드 프로그램과 의존성은 Git에 포함하지 않습니다.

## 도구와 주의 사항

[Umamo 공식 저장소](https://github.com/umamoorg/umamo)의 0.3.0-dev 배포본에 포함된 PSD 리더, CMO3/MOC3 코덱, 텍스처 패커 및 변형 평가기를 사용합니다. 직접 추측한 바이너리 형식으로 모델 파일을 작성하지 않습니다. 원본에 개인별 절대 경로를 기록하지 않으며, 모델에는 프로젝트 안의 상대 파일 이름을 사용합니다.

Umamo는 알파 단계의 무료 오픈소스 도구입니다. 작업 중 파일은 별도 복사본으로 보관하십시오. 형식 호환성과 모델의 시각적 완성도를 같은 의미로 취급하지 않습니다.

## 보완 이미지 생성 사양

내장 이미지 생성 도구를 사용했으며 CLI/API 별도 호출을 사용하지 않았습니다. 생성 사양의 핵심은 다음과 같습니다.

- 피부 밑그림: 기존 얼굴 파츠의 윤곽·기울기·피부색·코를 유지하고 눈·눈썹·입이 분리될 영역을 깨끗한 피부로 보완합니다. 투명 배경, 부드럽고 정돈된 선과 셀/소프트 셰이딩을 유지하며 얼룩·그레인·번짐을 추가하지 않습니다. 저장 파일은 `underpaint/face-clean-generated.png`입니다.
- 원단 밑그림: 기존 전신의 자세·옷 형태·흰색/검정/빨강/파랑 원단 배색·머리·얼굴·흰색 꼬리와 검은 꼬리 끝을 유지합니다. 분리할 부착 장식 아래의 천을 보완하고 원래 옷을 새 디자인으로 교체하지 않습니다. 투명 배경, 깔끔한 셰이딩을 요청하며 과도한 광원 효과·자글거림·파티클을 제외합니다. 저장 파일은 `underpaint/fabric-clean-generated.png`입니다.

생성 결과가 원화와 완전히 일치한다고 가정하지 않습니다. 원단의 실제 적용은 `prepare-rig-parts.py`의 숨은 영역 마스크와 원단 재질 검사로 제한합니다. 피부는 `Face` 파츠 안에서 채색을 이어 적용하며, 다른 특징 파츠를 생성 이미지로 교체하지 않습니다.
