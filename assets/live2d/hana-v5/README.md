# 하나: 단순한 머리카락과 셀·소프트 셰이딩 시안

## 요청 반영

사용자가 제시한 표현 지침을 `PROMPT.txt`에 포함하여 내장 이미지 생성 도구로 다시 생성하였습니다. V4 원화는 디자인 참고 자료로 사용하였습니다. 기존 그림에 배경 제거 마스크나 노이즈 제거 필터를 적용한 결과가 아닙니다.

- 머리카락은 잔머리 중심 표현에서 큰 다발과 명확한 곡선 중심으로 단순화하도록 요청하였습니다.
- 부드럽고 정돈된 선, 깔끔한 셀 셰이딩 및 넓은 소프트 셰이딩을 사용하도록 요청하였습니다.
- 자글거림, 모아레, 필름 그레인, 반짝이, 파티클 및 블룸을 제외하도록 요청하였습니다.
- 의상 배색·치마 패널·테두리·장식과 두꺼운 흰 꼬리의 검은 말단은 디자인 유지 항목으로 지정하였습니다.

## 결과 파일

| 파일 | 용도 |
| --- | --- |
| `hana-clean-native.png` | 생성 원본의 변경 없는 복사본. 실제 규격은 1024 × 1536, RGBA PNG입니다. |
| `hana-clean-4x.png` | 4096 × 6144 RGBA 작업 후보. 로컬 AI 확대본이며 해당 해상도의 원생성 결과는 아닙니다. |
| `PROMPT.txt` | 사용자 표현 지침을 포함한 실제 생성 지시문입니다. |
| `qa/checkerboard-preview.png` | 투명 영역을 확인하기 위한 격자 합성 미리보기입니다. 미리보기 자체에는 격자가 포함됩니다. |
| `qa/preview-*.png` | 밝은색·어두운색·청색 배경 합성 검수본입니다. |
| `qa/head-4x.png`, `qa/tail-4x.png` | 확대본의 머리와 꼬리를 잘라 표시 크기로 축소한 검수 이미지입니다. |
| `qa/report.json` | 생성 원본의 해상도 및 알파 검사 기록입니다. |

생성 원본과 확대본의 머리·꼬리 표현 및 다른 배경 위의 합성 결과를 육안 검토하였습니다. 미세한 질감의 부재를 수학적으로 보장하는 검사는 아니며, 현재 결과는 사용자 확인 전 시안입니다. 작은 장식의 표현은 재생성 과정에서 달라질 수 있습니다.

생성 파일의 캐릭터 내부 알파는 주로 250~254이며, 임의로 255로 보정하지 않았습니다. 확대 단계에서는 RGB에 기존 Real-ESRGAN 도구를 적용하고 원래 알파를 보간하였습니다. 새로운 배경 분리 모델을 사용하지 않았고 저장 알파와 보간 알파의 일치 검사를 통과하였습니다. 도구와 모델은 기존 로컬 설치를 재사용하였습니다.

이 결과는 평면 PNG입니다. 선화·색면이 레이어로 분리된 PSD나 정밀 파츠·리깅 완료본이 아닙니다. 기존 승인본 및 V4 파일은 변경하지 않았습니다. TTS·음성·기억 데이터와 앱 실행 코드는 수정하지 않았습니다.

## 재현 명령

프로젝트 루트에서 Node.js, `sharp` 및 기존 로컬 확대 도구를 사용할 수 있는 환경으로 실행합니다. 관련 설치 위치와 처리 방식은 [V4 안내](../hana-v4/README.md)를 참고합니다.

```powershell
node tools/live2d/review-transparent.cjs assets/live2d/hana-v5/hana-clean-native.png
node tools/live2d/upscale-transparent.cjs assets/live2d/hana-v5/hana-clean-native.png
```
