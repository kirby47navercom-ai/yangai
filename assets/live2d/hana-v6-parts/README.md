# 하나 V6 파츠 분리 초안

## 작업 상태

본 폴더는 `../hana-v6/hana-refined-4k.png`를 기준으로 제작한 **가시 영역 분리 초안**입니다. 캔버스는 4096 × 6144이며, 검토용 잔여 픽셀 레이어를 포함하여 165개의 래스터 레이어가 있습니다. **정밀 분해 완료본이나 즉시 리깅 가능한 모델이 아닙니다.**

원화를 다시 생성하거나 의상·색·장식을 지우지 않고, 기존 RGBA 픽셀을 레이어별로 배정하였습니다. 전체 레이어를 원래 좌표에 배치한 결과는 원화의 가시 픽셀 및 알파와 일치합니다. 다만 이 검사는 누락·변색 여부만 검증하며, 각 픽셀이 의미상 올바른 파츠에 배정되었음을 증명하지 않습니다.

실제 조각을 펼쳐 확인한 결과, 일부 머리·의상·장식의 경계에는 인접 부위가 섞이거나 잔여 조각이 남아 있습니다. 이 때문에 자동 검사 결과에도 `semanticBoundaryReview: INCOMPLETE`, `fineSeparationComplete: false`, `rigReady: false`를 기록하였습니다. 레이어 수를 정밀 제작 완료의 근거로 사용해서는 안 됩니다.

## 파일 구성

| 경로 | 용도 |
| --- | --- |
| `hana-visible-parts.psd` | 그룹과 원래 좌표를 유지한 165레이어 PSD 초안입니다. |
| `parts/` | 각 레이어의 외접 영역으로 잘라낸 투명 PNG입니다. PNG마다 크기가 다릅니다. |
| `parts.json` | PNG의 원래 좌표, 크기, 그룹, 픽셀 수, 파일 해시와 검토 상태입니다. |
| `cuts.cjs` | 현재 원화에 맞춘 절단 경로와 국소 경계 보정 설정입니다. |
| `assembled.png` | 모든 조각을 원래 위치에 되돌린 4096 × 6144 투명 재조합본입니다. |
| `qa/assembled-light.png`, `qa/assembled-dark.png` | 밝은색·어두운색 배경에서 확인하는 축소 재조합본입니다. |
| `qa/contact-01.png` ~ `qa/contact-09.png` | 모든 레이어를 실제 이미지로 펼친 검토 시트입니다. 작은 파츠는 확대 표시되므로 해상도 평가용이 아닙니다. |
| `qa/ownership.png` | 픽셀이 어느 레이어에 배정되었는지 보여 주는 색상 지도입니다. |
| `qa/report.json` | 자동 검사의 실제 측정값입니다. |
| `references/` | 절단 경로 작성에 사용한 좌표 격자 이미지입니다. |

PNG를 다시 조합할 때는 파일 중심을 맞추지 말고 `parts.json`의 `left`, `top`을 사용해야 합니다. `VL`과 `VR`은 캐릭터 기준이 아니라 **화면에서 보이는 왼쪽과 오른쪽**입니다. `Review_EdgeResidue`는 삭제 가능한 배경이 아니라, 다른 마스크에 배정되지 않은 원화의 가시 픽셀입니다.

## 분리한 범위

- 머리: 뒤쪽 머리, 좌우 묶음과 아래 컬, 앞쪽 흰 머리 다발, 빨강·파랑 앞머리, 삐침머리, 좌우 머리 장식입니다.
- 얼굴: 얼굴·목, 좌우 눈의 흰자·홍채·윗속눈썹·아래 경계, 눈썹·입·코를 별도 검토 레이어로 배치하였습니다.
- 상체: 안쪽 옷, 넥타이와 색 띠, 허리 의상·벨트·단추, 좌우 재킷과 안쪽 밑단·주머니·덮개·지퍼·끈·문양입니다.
- 팔: 좌우 소매와 아래 소매, 어깨끈·버클·팔띠·주머니·덮개·메달·술·리본·보석·소맷단입니다.
- 하체: 치마의 중앙·좌우 패널·배색 천·앞쪽 테두리, 금색 문양, 허리 장식·꽃·보석, 다리, 부츠·끈·장식입니다.
- 꼬리: 뿌리 쪽, 아래 곡선, 올라가는 곡선, 검은 끝과 색 전환 영역을 포함한 끝부분입니다. 검정·흰색의 부드러운 털 경계를 톱니 모양으로 잘라내지 않았습니다.

## 완료되지 않은 항목

1. **정확한 경계 정리:** 흰 머리 다발 사이, 얼굴·목·깃, 소매·소맷단, 치마 패널·장식, 부츠 장식 등에 인접 색이나 선이 일부 포함되어 있습니다. 작은 금속 장식에는 원래 천이 붙어 있거나 다른 장식이 일부 겹친 조각도 있습니다. 재조합하면 보이지 않지만 개별 이동 시 드러납니다.
2. **잔여 픽셀 배정:** `Review_EdgeResidue`와 큰 기본 레이어에 남아 있는 작은 조각의 소속을 추가 확인해야 합니다. 자동으로 삭제하지 않았습니다.
3. **추가 세분화:** 손가락, 손톱, 홍채 내부의 동공·반사광, 꽃잎 각각, 머리 장식의 각 연결부, 묶음 머리의 세부 다발은 모두 완성된 독립 파츠가 아닙니다. 전체 모양이 손상되는 임의 절단은 적용하지 않은 곳도 있습니다.
4. **가려진 면 복원:** 앞머리에 가린 이마, 장식 뒤의 천, 머리 다발의 뿌리, 팔·다리·꼬리의 연결 여유분은 그리지 않았습니다. 현재 레이어에는 다른 파츠를 떼어낸 구멍이 있습니다. 픽셀 분리만으로 원화에 없는 면을 복원할 수는 없습니다.
5. **표정 원화:** 눈을 감은 모양, 입 안·치아·혀와 발음별 입 모양은 준비되지 않았습니다.
6. **리깅 및 앱 검사:** Cubism에서 불러오기, 메시, 디포머, 파라미터, 물리 연산 및 움직임 검사는 수행하지 않았습니다. PSD 저장과 재읽기 검사는 실제 Cubism 호환성 확인과 다릅니다.

## 검사와 파일 형식

입력 PNG의 SHA-256은 다음과 같습니다.

```text
f91e25e12a870c202511d97912caa3ed196563a6e8052a314b0f965ab571e00a
```

생성 스크립트는 입력 해시·크기, 고유 레이어 이름, 미배정 가시 픽셀, 가시 RGBA 재조합, PNG 재읽기, PSD 재읽기 시 레이어 수·좌표·RGBA 일치 여부를 검사합니다. 완전 투명 픽셀의 보이지 않는 RGB 값은 비교 대상에서 제외합니다. 원화 자체에 존재하는 내부 반투명 픽셀은 원래 값을 유지합니다.

PSD는 RGB·8비트·일반 혼합·불투명도 100%이며, 조각의 알파는 각 래스터 레이어에 들어 있습니다. 레이어 마스크나 클리핑 마스크로 구성하지 않았습니다. 별도 sRGB ICC 프로필 삽입은 확인하지 않았습니다.

Live2D 공식 문서도 가려진 영역의 추가 작화와 파츠별 래스터 정리를 안내합니다. 현재 파일은 그 전 단계의 작업 자료입니다. [PSD 준비 튜토리얼](https://docs.live2d.com/en/cubism-editor-tutorials/psd/), [PSD 가져오기 주의사항](https://docs.live2d.com/en/cubism-editor-manual/precautions-for-psd-data/).

## 재생성

프로젝트 루트에서 실행합니다. Node.js의 `sharp`, `@napi-rs/canvas`, `ag-psd` 및 `python` 명령에서 사용할 수 있는 NumPy·OpenCV가 필요합니다. 이번 작업에서는 이미 설치된 패키지를 사용하였으며, 별도 의존성 설치는 수행하지 않았습니다.

```powershell
node tools/live2d/trace-reference.cjs
node --max-old-space-size=8192 tools/live2d/split-visible.cjs
```

모듈이 전역 검색 경로에 없는 환경에서는 해당 설치 위치를 `NODE_PATH`에 지정해야 합니다. 실제 사용자 폴더의 절대 경로는 저장소에 기록하지 않습니다. 국소 색상 분리와 경계 보정은 `tools/live2d/refine-visible.py`에서 수행되며, 관련 입력·중간 마스크는 Git에서 제외된 `.local-tools/live2d/refine-v6/`에 저장됩니다. 원화는 외부 서버에 전송하지 않았습니다.

동일 실행은 본 폴더의 파생 파일을 갱신합니다. PSD를 직접 수정한 경우 재실행 전에 별도 이름으로 보존해야 합니다. 원화와 이전의 제외된 분해 시도는 삭제하지 않았습니다. TTS·음성 파일, 앱 코드와 기억 데이터는 이번 변경에 포함하지 않았습니다.
