# 하나 V8 동작 초안

V7 전신 파츠를 기반으로 표정·시선·입 움직임과 연결 변형을 추가한 모델입니다. **완성된 전신 재작화·상용 수준의 최종 리깅 모델이 아닙니다.** 큰 움직임에서 가려진 면과 일부 조각 경계가 드러납니다. 기존 원화와 V7 PNG 파츠는 보존합니다.

## 실행

프로젝트 루트의 `check_hana_avatar.vbs`를 실행하면 대화 모델·마이크·화면·TTS 서버 없이 모델을 확인할 수 있습니다. 평상시·미소·기쁨·슬픔·눈물·화남·놀람 버튼과 마우스 추적·자동 깜박임을 사용합니다. 정상 방송은 새 `dist/Hana/Hana.exe`에서 실행합니다. 같은 표정 확인 메뉴가 GUI 왼쪽에 있으며 다음 대사에서는 모델이 선택한 표정으로 전환됩니다.

Umamo의 `File` → `Import CMO3`에서 `umamo/hana.cmo3`를 열면 파츠·메시·변형기·파라미터를 편집할 수 있습니다. 편집한 파일은 재생성 명령에 의해 덮어써지지 않도록 다른 이름으로 저장하십시오. 해당 버전의 Umamo는 아직 알파 단계이므로 원본의 복사본을 사용하십시오.

## 실제 구성

| 항목 | 구성 |
| --- | --- |
| 원화 좌표 | 4096 × 6144 픽셀, 기존 파츠 위치 유지 |
| 표시 파츠 | 기존 191개와 말하는 입·양쪽 눈물 3개, 총 194개 |
| PSD | 194개 표시 파츠와 비활성 눈 작업용 마스터 24개, 총 218레이어 |
| 네이티브 리그 | 회전 변형기 65개, 연결 워프 15개, 파라미터 82개, 메시 정점 7077개 |
| 텍스처 | 4096 × 4096 아틀라스 2장 |
| 표정 | 평상시, 미소, 기쁨, 슬픔, 눈물, 화남, 놀람 |
| 눈 | 원화 홍채·동공·반사광을 유지하고 흰자 클리핑을 적용합니다. 양쪽 눈 뜨기와 시선 이동을 분리합니다. 감았을 때는 속눈썹 두께를 별도 변형으로 보존합니다. |
| 입 | 원화의 닫힌 입과 생성한 열린 입을 전환하고 크기·표정을 변형합니다. 실제 WAV 재생 음량으로 개폐합니다. |
| 전신 | 작은 몸통 회전·호흡, 연결된 팔·머리카락·꼬리의 작은 움직임을 재생합니다. |

V8에서는 팔·머리카락·꼬리를 움직일 때 같은 면의 조각들이 따로 떨어지지 않도록 공유 워프에 연결했습니다. 이 영역의 이전 개별 회전 파라미터 일부는 V8에서 파츠에 직접 연결되지 않습니다. 65개 회전 변형기가 있다는 사실이 65개 모두 최종 독립 동작을 수행한다는 의미는 아닙니다. V7의 기존 개별 회전 초안은 별도로 보관합니다.

## 파일과 원화 보존

- `parts.json`: 전체 194개 파츠의 이름·원화 위치·PNG 참조입니다. 189개 PNG는 V7의 기존 파일을 참조하고, 흰자 2개와 열린 입·눈물 3개만 이 폴더에 저장합니다.
- `hana-rig-source.psd`: 현재 파츠를 원화 좌표에 놓은 편집용 PSD입니다. 열린 입과 눈물의 기본 불투명도는 0입니다.
- `umamo/hana.cmo3`: 편집 가능한 실제 모델입니다.
- `umamo/hana.model3.json`, `hana.moc3`, `hana.cdi3.json`, `hana-textures/`: 앱 재생용 묶음입니다. 함께 보관해야 합니다.
- `preview.html`: 이전 방식의 PNG 회전 초안입니다. V8의 워프·표정·클리핑을 구현한 재생기는 아니므로 최종 동작 확인에 사용하지 않습니다.
- `qa/runtime-*.png`, `qa/runtime-expressions.png`: 실제 Live2D 재생기로 렌더링한 기본·표정·눈 감기·입 열기·양쪽 움직임 검사 이미지입니다.
- `qa/motion-preview.webp`: 무음 동작 시험입니다. 입은 합성한 시험 음량으로 움직이므로 실제 음성이 들렸다는 증거가 아닙니다.
- `qa/umamo-rig.json`: 저장·다시 읽기·좌표·순서 검사 결과입니다.
- `qa/runtime.json`, `qa/review.json`: 네이티브 재생 결과와 육안 확인·남은 문제를 구분하여 기록합니다.

흰자는 홍채가 이동했을 때 기존 구멍이 드러나지 않도록 그 아래만 채웠습니다. 홍채·동공·반사광을 단색 원이나 타원으로 바꾸지 않았습니다. 기존 숨은 작업용 원형 눈 마스터는 비활성 상태이며 런타임에 표시하지 않습니다. 텍스처를 내보낼 때 완전히 투명한 픽셀의 RGB를 주변 색으로 이어서 검은 필터링 경계선을 줄입니다. 이 과정은 알파와 보이는 픽셀을 변경하지 않으며 자동으로 검사합니다.

## 표정·립싱크 흐름

대사 생성 모델은 구조화된 결과의 `expression`에 `neutral`, `smile`, `happy`, `sad`, `cry`, `angry`, `surprised` 중 하나를 선택합니다. 검사를 통과하여 실제로 출력하는 대사에 대해서만 GUI 표정을 갱신합니다. 알 수 없는 값은 평상시로 처리하며, 내부 표정 이름을 음성으로 읽지 않습니다. 선택된 표정은 방송 상태와 함께 기억에 저장합니다. 표정 선택의 정확성은 대화 모델의 판단에 의존하므로 모든 발언에 대해 보장하지 않습니다.

Piper와 GPT-SoVITS 모두 기존의 공통 WAV 재생 함수를 사용합니다. 재생 중 50ms PCM 구간의 RMS 음량을 전달하여 입을 움직이며, 합성 대기 상태만으로 입을 움직이지 않습니다. 침묵·취소·종료·오래된 신호는 입을 닫게 합니다. 기존 TTS 모델, 음성 파일, 울림·속삭임 설정을 변경하지 않습니다. 실제 출력 장치에서 들리는 시각을 측정한 정밀 오디오 동기화나 모음별 입 모양은 구현하지 않았습니다. 필요하면 `config.json`의 `avatar_lip_gain`을 0.5~20 사이로 지정할 수 있습니다. 기본값은 5입니다.

앱은 커서 위치를 읽을 뿐 커서를 이동·숨김·고정하지 않습니다. 마우스 추적을 끄면 고개와 시선이 부드럽게 정면으로 돌아옵니다. 깜박임·호흡·작은 움직임은 대화 모델의 응답을 기다리지 않고 GUI에서 계속 재생합니다. 현재의 머리·꼬리 흔들림은 주기 운동이며 물리 시뮬레이션이 아닙니다.

## 검증과 제한

CMO3와 MOC3의 저장 전후 102개 자세 좌표·파츠 표시 순서를 검사했습니다. 기존 65개 파라미터의 양수 끝점과 새 17개 파라미터의 양 끝점을 포함합니다. 연결되지 않은 이전 파라미터의 자세도 저장 보존 검사는 통과할 수 있으므로, 검사 개수를 실사용 동작 개수로 해석하지 않습니다. 실제 앱 GUI의 GL 표면 생성과 표정 전달, WAV 재생 콜백·취소·침묵, 마우스 범위·깜박임·신호 만료를 별도로 검사합니다. 마이크를 사용하거나 방송 기록을 시험 데이터로 변경하지 않습니다.

초기 5.3 및 4.2 대상으로 내보낸 MOC3는 자체 디코딩을 통과했지만 Live2D Core의 파일 일관성 검사를 통과하지 못했습니다. 현재 사용한 전통적인 회전·삼각 워프 기능만 포함하여 **Cubism 3.0 대상**으로 내보낸 파일은 Core 검사와 실제 렌더링을 통과했습니다. CMO3는 편집용 최신 형식으로 유지합니다. 자체 읽기 성공을 외부 런타임 호환 확인으로 취급하지 않습니다. 앱에서도 일관성 검사를 통과하지 못한 모델은 로드하지 않습니다.

새로 빌드한 windowed EXE도 `--avatar-check`로 실제 실행하여 번들 안의 네이티브 재생기, 82개 파라미터, 입·눈물의 렌더링과 종료 코드 0을 확인했습니다. 프로젝트 밖의 작업 디렉터리에서 한글 경로에 있는 모델도 로드했습니다. 이 시험은 마이크·화면·LLM·TTS 서버를 시작하지 않으며, 출력 장치에서 목소리가 들리는지까지 확인한 시험은 아닙니다. 진단 결과는 실행 폴더의 `data/diagnostics/avatar-built.json`에 저장되고 공개 저장소에는 포함하지 않습니다.

확인한 기본 표정·눈 감기·입 열기·작은 움직임은 동작합니다. 그러나 큰 머리·머리카락 움직임의 어깨 근처, 소매와 장식 접합부, 일부 다리 경계, 꼬리 끝의 작은 조각은 추가 보완이 필요합니다. 가려진 신체·의상·머리카락 전체를 재작화한 상태가 아닙니다. 정교한 얼굴 3D 회전, 고급 물리, 완전히 독립적인 장식 움직임, 울음·웃음의 다양한 입 교체 그림도 완료하지 않았습니다. **전체 완성 여부는 미완성으로 기록합니다.**

## 재생성 및 검사

프로젝트 루트에서 기존 Node 이미지 의존성을 연결한 후 다음을 실행합니다. 생성한 열린 입의 원본은 인수로 지정하며 개인별 절대 경로를 모델에 저장하지 않습니다.

```text
node tools/live2d/prepare-live.cjs <투명_열린_입_PNG>
node tools/live2d/build-rig.cjs assets/live2d/hana-v8-live
powershell -NoProfile -File tools/live2d/build-umamo.ps1 -OutputDirectory assets/live2d/hana-v8-live
.venv/Scripts/python.exe tools/live2d/check-avatar.py
.venv/Scripts/python.exe -m unittest test_avatar test_hana test_voice test_inputs test_autonomy test_grounding test_dialogue_quality
```

열린 입은 내장 이미지 생성 도구로 작성했습니다. 기존 얼굴의 얇은 갈색 선과 셀 셰이딩, 약간 비대칭인 미소를 참고하여 입 내부·작은 혀·윗니·오른쪽 작은 송곳니만 투명 배경에 생성했습니다. 얼굴·피부·여러 입 형태·문자·그레인·블룸은 제외하도록 요청했습니다. 적용 PNG는 원화의 입 위치에 맞추어 잘라서 배치했으며, 원화의 다른 영역을 생성 결과로 덮지 않습니다.

사용한 구현은 [Umamo](https://github.com/umamoorg/umamo), [live2d-py](https://github.com/EasyLive2D/live2d-py), [pyopengltk](https://github.com/jonwright/pyopengltk)입니다. Umamo의 무료 편집기를 유지하며 Cubism 유료 편집기를 설치하지 않습니다. 재생기 안의 Live2D Core 및 SDK에는 별도의 [Live2D 라이선스](https://www.live2d.com/en/sdk/license/)가 적용되므로, 재배포·상업적 이용 시 해당 조건을 확인하십시오. 음성 모델 파일과 로컬 다운로드 도구는 Git에 포함하지 않습니다.
