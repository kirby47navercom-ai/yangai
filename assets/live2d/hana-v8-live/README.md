# 하나 V8: 재작화 기반 동작 초안

보이는 픽셀만 잘라 연결한 방식에서, **완전한 재질 면을 먼저 작성하고 그 위에 세부 파츠를 배치하는 방식**으로 수정한 모델입니다. 전신 주요 면과 재생기의 경계선을 보완하였지만, 모든 머리카락·장식의 숨은 면과 독립 동작까지 완성한 최종 모델은 아닙니다. 원본 4K 원화와 V7은 변경하지 않습니다.

## 실행 및 편집

프로젝트 루트의 `check_hana_avatar.vbs`를 실행하면 대화 모델·마이크·화면·TTS 없이 마우스 추적, 자동 깜박임과 7종 표정을 확인할 수 있습니다. 정상 방송은 다시 빌드한 `dist/Hana/Hana.exe`에서 실행합니다. 커서는 읽기만 하며 이동·숨김·고정하지 않습니다.

`preview.html`은 실제 네이티브 재생기로 렌더링한 무음 동작과 고개·표정 검사 이미지를 보여 줍니다. V8에서는 PNG 조각을 개별 회전시키는 예전 웹 미리보기를 표시하지 않습니다. 실제 마우스 추적은 앱에서 확인하십시오.

Umamo의 `File` → `Import CMO3`에서 `umamo/hana.cmo3`를 열어 편집할 수 있습니다. 직접 편집한 결과는 다른 이름으로 저장하십시오. 재생성 명령은 자동 생성 결과를 덮어씁니다. 알파 버전이므로 복사본을 사용하는 것이 안전합니다. Cubism 유료 편집기는 설치하지 않습니다.

## 재작화 범위

| 대상 | 적용 내용 |
| --- | --- |
| 얼굴·목 | 머리카락 모양으로 패인 피부 조각 대신 완전한 피부 면을 사용합니다. 눈·눈썹·코·입과 머리카락은 별도 레이어입니다. |
| 앞머리 | 흰 머리, 빨간 앞머리, 파란 앞머리를 머리카락 재질만 포함하는 그림으로 교체합니다. 피부 삼각형이나 장식 파편을 섞지 않습니다. |
| 양쪽 묶음머리 | 완전한 머리카락 묶음을 아래 면으로 배치합니다. 일부 작은 가닥의 완전한 숨은 면 재작화는 남아 있습니다. |
| 망토 | 빨강·파랑 천을 고정 장치와 분리하여 작성합니다. 검은 칼라는 별도 파츠입니다. |
| 속옷·치마 | 장식 구멍이 없는 검은 천과 빨강·파랑·흰색 배색을 유지합니다. 옆면도 같은 천 그림을 사용하여 꽃·고리·끈이 천에 붙은 상태로 남지 않게 합니다. |
| 재킷·소매 | 장식 없는 흰 천을 먼저 작성합니다. 소매 상·하부의 관절은 같은 그림을 겹쳐 명암이 이어지게 합니다. |
| 주머니 | 가슴·소매 주머니의 흰 천을 별도로 작성합니다. 금속·끈 아래도 천으로 채우고 덮개를 같은 원본에서 분리합니다. |
| 손목·완장 | 단추 자국 없는 빨강·파랑 천과 검은 완장 천을 작성합니다. 손톱 색은 보존하고 손 파츠의 손목 천 조각은 제거합니다. |
| 다리 | 연속된 스타킹 그림을 원화의 다리 실루엣·무릎 높이에 맞추어 나눕니다. 관절 겹침은 같은 픽셀을 사용합니다. |
| 부츠 | 뒤쪽 입구·안감 → 종아리 → 앞쪽 입구·가죽 순서로 겹칩니다. 안감을 다리 위에 덮지 않으며 다리와 부츠는 같은 연결 워프를 사용합니다. 앞코·밑창·띠는 같은 그림에서 분리합니다. |
| 꼬리 | 잘린 오른쪽 외곽을 투명 캔버스에서 다시 작성합니다. 완전한 외곽을 원화 안에 배치하고 세부 영역은 같은 그림을 겹쳐 사용합니다. |
| 금속 일부 | 허리 고리·체인 내부에 남은 옷 픽셀을 제거합니다. 모든 금속 장식의 가려진 윤곽을 완성한 것은 아닙니다. |

생성 그림을 원화 좌표에 맞추는 과정에서 일부 주름·실루엣은 기존과 달라졌습니다. 원화 픽셀과 완전히 동일한 복원이나 전문 작화가의 최종 정밀 분리 결과로 소개하지 않습니다.

## 파일과 수량

- `parts.json`, `parts/`: 표시 파츠의 좌표와 프로젝트 내부 투명 PNG입니다. V7 외부 PNG를 참조하지 않습니다.
- `underpaint/semantic/`: 재작화 원본과 [프롬프트 기록](underpaint/semantic/README.md)입니다. 내장 이미지 생성 도구로 작성하고 프로젝트에 복사하였습니다.
- `hana-rig-source.psd`: 편집용 PSD입니다. 비활성 눈 마스터 24개는 실행 시 사용하지 않습니다.
- `umamo/hana.cmo3`: 편집 가능한 모델입니다.
- `umamo/hana.model3.json`, `hana.moc3`, `hana.cdi3.json`, `hana-textures/`: 앱 재생용 묶음입니다.
- `qa/contact-*.png`: 파츠 점검용 판입니다. 모든 조각의 정밀 작화가 통과했다는 의미는 아닙니다.
- `qa/runtime-*.png`, `qa/motion-preview.webp`: 실제 재생기의 표정·깜박임·입 열기·고개·전신 시험입니다. 영상의 입은 합성 시험 음량에 반응하며 음성 출력 시험이 아닙니다.
- `qa/pose-*.png`: 예전 개별 회전 방식의 비교 자료이며 현재 동작의 승인 자료가 아닙니다.
- `qa/surfaces.json`, `visual.json`, `umamo-rig.json`, `runtime.json`: 파일·픽셀·저장·재생 검사입니다. 미술적 완성을 보증하지 않습니다.
- `qa/review.json`: 육안 확인·실행 파일 검사·남은 문제 기록입니다.

표시 파츠는 193개, PSD는 비활성 마스터를 합하여 217레이어입니다. 부츠 뒤쪽 입구 2개를 추가하였습니다. 예전 파란 앞머리 끝의 잘못된 조각 3개는 현재 묶음에서 제외하였으며 V7 자료는 보존합니다. 회전 변형기 62개, 연결 워프 21개, 파라미터 80개가 있습니다. 메시 정점 수는 `qa/umamo-rig.json`에 기록합니다.

텍스처는 4096 × 4096 아틀라스 3장입니다. 이전 2픽셀 간격에서는 작은 표시 크기에서 주변 텍스처가 섞여 직사각형 선이 생겼으므로 패킹 여유와 가장자리 확장을 32픽셀로 변경하였습니다. 패킹 과정은 원본 알파와 보이는 픽셀을 보존합니다. 파츠 작성 단계에서는 반투명으로 생성된 불투명 재질의 내부 알파를 255로 정규화하여 겹침의 사각 명암 단차를 제거합니다. 외곽의 낮은 알파 안티앨리어싱은 유지합니다.

## 움직임

얼굴 피부와 머리카락은 서로 다른 곡면 깊이로 좌우·상하 원근을 변형합니다. 눈·눈썹·코·입은 피부 워프를 공유하므로 얼굴 위를 따로 미끄러지지 않습니다. 입 표정은 중심이 아니라 양 끝을 조절하고, 열린 입의 윗선을 닫힌 입 위치에 연결합니다. 상하 회전축은 턱 뒤에 두어 고개를 들 때 목 전체가 과하게 늘어나지 않게 합니다. 목의 윗부분은 턱을 따르고 아랫부분은 몸통·옷깃에 고정합니다. 옷깃에 섞여 있던 옛 피부·턱 선은 제외합니다.

고개 범위를 축소하여 결함을 숨기지 않습니다. 앱의 좌우 20도·상하 15도 범위는 유지합니다. 시선이 먼저 움직이고 고개가 느리게 따라오며, 시작 시 커서가 끝에 있어도 고개·몸통을 즉시 최대 각도로 꺾지 않습니다. 묶음머리의 후속 움직임은 감쇠 스프링을 사용하여 고개가 멈추면 가라앉습니다. 앞머리를 별도 주기 운동으로 계속 밀지 않습니다. 얼굴 XY 키 조합의 일반적인 구성은 [Live2D 공식 설명](https://docs.live2d.com/en/cubism-editor-manual/synthesize-corners/)을 참고하였습니다.

몸통 원근·호흡은 상체와 의상을 함께 움직입니다. 팔·다리·꼬리는 그 계층에 연결합니다. 다리는 치마·꼬리 때문에 잘린 가시 픽셀 마스크를 해부학적 윤곽으로 재사용하지 않고, 연속된 그림을 허벅지·무릎·종아리·발목 위치에 맞춥니다. 같은 다리 워프가 부츠까지 연결되며 발목과 부츠 입구가 서로 다른 회전축으로 벌어지지 않습니다. 작은 대기 움직임에는 주기 운동이 남아 있습니다. 모든 옷·장신구의 독립적인 최종 물리를 적용한 것은 아닙니다. 기존 회전 파라미터 일부는 공유 워프로 대체되어 직접 파츠를 움직이지 않습니다. 파라미터 수를 독립 동작 수로 해석하지 마십시오.

평상시·미소·기쁨·슬픔·눈물·화남·놀람을 지원합니다. 실제 방송에서는 출력 대사의 `expression`을 GUI에 전달합니다. 원화 홍채·동공·반사광과 흰자 클리핑을 유지하며 단색 도형으로 바꾸지 않습니다. 정교한 감은 눈 교체 원화와 다양한 웃음·울음 입 모양은 추가 작화가 필요합니다.

기존 공통 WAV 재생 함수의 50ms PCM RMS 음량으로 입을 움직입니다. 합성 대기 중에는 입을 열지 않습니다. 발음별 입 모양이나 출력 장치 지연까지 보정한 립싱크는 아닙니다. 음성 모델과 울림·속삭임 설정은 변경하지 않습니다.

## 검사와 미완성 범위

CMO3 및 MOC3 저장 전후 101개 자세의 좌표와 표시 순서를 비교합니다. 저장 오차가 없다는 사실은 자연스러운 작화의 증거가 아닙니다. `qa/anatomy.json`에는 옷깃 고정점, 눈·입과 피부, 무릎·부츠의 실제 메시 좌표 차이를 기록합니다. 얼굴이 단순 평행이동만 하는지도 검사합니다. Live2D Core·GL 재생, 9방향 고개·7표정·양쪽 전신 동작, 고개·깜박임·발화를 동시에 적용한 자세, PSD 픽셀 보존·재조합과 관절 겹침을 별도로 검사합니다. MOC3는 Core를 통과한 Cubism 3.0 대상으로 내보내고 CMO3는 편집용 형식을 유지합니다.

**전신 정밀 완성은 미완성입니다.** 남은 범위는 다음과 같습니다.

1. 작은 머리카락 가닥의 새 분리선과 완전한 가려진 뿌리·끝이 필요합니다. 기존 가이드로 얻은 작은 조각을 최종 파츠로 취급하지 않습니다.
2. 금속·끈·단추·장신구 전체의 독립 윤곽과 가려진 부분은 추가 작화가 필요합니다. 옷 면 작성 완료와 모든 장식 완료는 다릅니다.
3. 전방 범위의 연결 원근은 구현하였지만 실제 3D 모델은 아닙니다. 완전한 옆면·뒷면 회전을 위해서는 별도의 방향별 원화·키폼이 필요합니다. 귀·머리 가닥의 독립적인 최종 메시와 세부 물리도 남아 있습니다.
4. 일부 소품의 각도·주름은 원화와 차이가 있으며 추가 조율이 필요합니다.

실행 파일은 서버를 시작하지 않는 `--avatar-check`로 확인합니다. 결과는 Git에서 제외한 실행 폴더의 `data/diagnostics/`에 저장합니다. 실제 음성 출력과 장시간 자율 대화는 이번 작화 검증 범위가 아닙니다.

## 재생성

기존 Node 이미지 의존성, Python의 Pillow·NumPy·OpenCV와 로컬 Umamo 도구를 사용합니다. `prepare-live.cjs`는 재작화 결과를 덮어쓰므로 현재 수정본의 재생성에는 사용하지 마십시오.

```text
node tools/live2d/export-guides.cjs
python tools/live2d/rebuild-surfaces.py
python tools/live2d/check-surfaces.py
node tools/live2d/build-rig.cjs assets/live2d/hana-v8-live
powershell -NoProfile -File tools/live2d/build-umamo.ps1 -OutputDirectory assets/live2d/hana-v8-live
.venv/Scripts/python.exe tools/live2d/check-avatar.py
.venv/Scripts/python.exe -m unittest test_avatar test_hana test_voice test_inputs test_autonomy test_grounding test_dialogue_quality
```

사용한 구현은 [Umamo](https://github.com/umamoorg/umamo), [live2d-py](https://github.com/EasyLive2D/live2d-py), [pyopengltk](https://github.com/jonwright/pyopengltk)입니다. Live2D Core와 SDK 재배포·상업적 이용에는 [별도 라이선스](https://www.live2d.com/en/sdk/license/)가 적용됩니다. 음성 모델과 로컬 도구는 Git에 포함하지 않습니다.
