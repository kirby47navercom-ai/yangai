# 하나 눈 색감 보완 V2 — 리깅 완성본 아님

## 변경 범위

기존 눈 보완본에서 원화의 색 구분과 입체감이 약해진 문제를 보완하기 위한 후보입니다. 전신 정밀 분해를 완료한 자료가 아니며, 눈 전체 이동 시험에서도 경계 결함이 확인되었습니다.

- 원래 얼굴을 참고하여 내장 이미지 생성 도구로 빨강·파랑 홍채 바탕을 다시 제작하였습니다. 사용 프롬프트는 `PROMPT.txt`에 기록하였습니다.
- 생성된 홍채를 각각 664 × 664 픽셀의 PNG 마스터로 추출하였습니다. 확대하지 않았으며, 생성 원본의 알파와 짙은 외곽 테두리를 보존하였습니다.
- 홍채 바탕, 동공, 반사광, 흰자, 속눈썹, 눈꺼풀 및 눈꺼풀 그림자를 구분한 26레이어 PSD를 저장하였습니다.
- 하단 반사광은 양쪽 모두에 배치하였습니다. 원래 파란색 반사광의 알파 윤곽을 복제하여 빨간 눈에는 연분홍색, 파란 눈에는 연파란색으로 적용하였습니다. 홍채 반지름에 대한 위치와 크기 비율은 동일합니다.
- 눈꺼풀 그림자는 별도의 전면용 반투명 마스크입니다. 홍채가 이동할 때 그림자의 위치는 눈꺼풀 쪽에 남습니다. 홍채 내부의 기본 색상 명암까지 모두 개별 레이어로 분해한 것은 아닙니다.
- 기존 동공·흰자·반사광 보완 원화, 속눈썹·눈꺼풀 추출물 및 피부 보완은 재사용하였습니다. 이 부분을 새로 정밀 작화한 것은 아닙니다.
- 기존 `../eye-motion/` 및 전신 원화·분해 PSD는 변경하지 않았습니다.

## 파일

- `hana-eye-motion-parts.psd`: 4096 × 6144 원래 좌표의 눈 전용 PSD입니다. 전신 PSD가 아닙니다.
- `masters/VL_Iris.png`, `masters/VR_Iris.png`: 축소하지 않은 새 홍채 마스터입니다.
- `parts/`, `parts.json`: 원화 크기로 배치한 개별 PNG, 좌표, 검사 결과입니다.
- `qa/face-comparison.png`: 위부터 원래 얼굴, 이전 V1, 새 V2의 실제 픽셀 크기 비교입니다.
- `qa/gaze-test.png`: 여덟 상태의 합성 검사입니다. **마지막 행의 두 상태**는 눈 전체 이동이며, 피부·머리 경계 결함이 드러납니다.
- `qa/gaze-test.webp`: 홍채 이동 합성 애니메이션입니다. Cubism 실행 결과가 아닙니다.
- `source/iris-painted.png`: 수정하지 않은 생성 원본입니다.

## 확인 결과

PSD 저장 후 다시 읽었을 때 26개 레이어의 좌표와 RGBA가 저장 전과 일치하였습니다. 하단 반사광 마스터의 좌우 알파가 일치하고, 배치된 반사광 파츠의 크기도 같은 것을 검사하였습니다. 홍채 내부 검사 범위에서 알파 240 미만의 결손은 없었으며, 여덟 상태의 완전히 열린 눈 마스크 내부에서 알파 250 미만의 빈틈은 없었습니다. 생성 홍채는 내부 알파도 주로 252~253이므로 완전 불투명 이미지라고 표기하지 않습니다.

이 검사는 미술 품질이나 실제 리깅 성공을 보증하지 않습니다. 새 홍채에는 기존보다 내부 무늬가 많으며, 원래 얼굴의 눈을 픽셀 단위로 복원한 결과가 아닙니다. 최종 그림체 채택 여부는 비교 이미지로 판단해야 합니다.

**눈 전체 이동 품질 검수는 실패입니다.** 기존 피부 보완과 일부 눈꺼풀·머리 경계에 이음새와 잔여 픽셀이 보입니다. 감은 눈, 눈을 크게 뜬 상태, 회전, Cubism 불러오기 및 디포머·물리 설정도 완료하지 않았습니다. `rigReady`와 `cubismImportTested`는 `false`입니다.

## 클리핑 및 재생성

홍채·동공·반사광은 같은 쪽 `Sclera_Opening`을 기준으로 클리핑해야 합니다. `Lid_CastShadow`는 같은 쪽 홍채에 클리핑하되 움직임은 눈꺼풀에 연결해야 합니다. PSD는 이러한 Cubism 연결을 완료한 파일이 아닙니다.

프로젝트 루트에서 설치된 `sharp`, `@napi-rs/canvas`, `ag-psd`를 사용할 수 있는 Node 환경으로 다음 명령을 실행합니다. 신규 의존성 설치는 필요하지 않습니다.

```powershell
node --max-old-space-size=8192 tools/live2d/prepare-eyes.cjs v2
```

공통 원화는 `../eye-motion/source/`에서 읽습니다. 기본 인자 없이 실행하면 기존 V1 제작 경로를 사용하므로, V2를 만들 때에는 `v2` 인자를 생략하지 않아야 합니다.
