# 하나 V6 분해 보정 및 눈 움직임용 보완 원화

## 현재 상태

본 폴더에는 원화의 가시 픽셀을 보존한 **분해 수정 초안**과, 가려진 부분을 추가한 **눈 전용 보완 원화**가 함께 있습니다. 두 자료의 목적과 검증 범위가 다르므로 구분하여 사용해야 합니다. 전체 캐릭터의 정밀 분해 또는 리깅이 완료된 결과물은 아닙니다.

기존 `../hana-v6-parts/`의 원본 분해본과 `../hana-v6/hana-refined-4k.png`는 변경하지 않았습니다. TTS·음성 파일 및 애플리케이션 코드는 이번 작업에 포함하지 않았습니다.

## 주요 파일

| 파일 | 내용 |
| --- | --- |
| `hana-visible-parts.psd` | 4096 × 6144, 192개의 가시 픽셀 레이어입니다. 기존 분해 경계를 수정한 중간 자료입니다. |
| `parts/`, `parts.json` | 기존 원화에서 추출한 PNG, 원래 좌표, 크기 및 검사 상태입니다. |
| `assembled.png` | 가시 픽셀 분해본의 재조합 결과입니다. 원화와 가시 RGBA가 일치합니다. |
| `eye-motion/hana-eye-motion-parts.psd` | 같은 4096 × 6144 좌표에 배치한 23레이어 눈 전용 보완 PSD입니다. 전신 PSD가 아닙니다. |
| `eye-motion/masters/` | 축소하지 않은 눈 보완 파츠 마스터입니다. 홍채는 각각 352 × 352 PNG입니다. |
| `eye-motion/parts/`, `eye-motion/parts.json` | 캐릭터의 원래 눈 크기에 배치한 파츠와 좌표, 검사 범위입니다. |
| `eye-motion/qa/underpaint-parts.png` | 둥근 홍채와 흰자, 동공, 반사광을 분리하여 표시한 검토 시트입니다. |
| `eye-motion/qa/gaze-test.png`, `gaze-test.webp` | 시선 이동 합성 검사입니다. 실제 Cubism 실행 화면이 아닙니다. |
| `eye-motion/qa/whole-eye-test.webp` | 피부 보완 위에서 눈꺼풀과 눈 내부를 함께 옮기는 소범위 합성 검사입니다. |
| `eye-motion/PROMPTS.md` | 보완 원화 생성에 사용한 프롬프트와 채택·제외 내역입니다. |

`VL`과 `VR`은 화면에서 보이는 왼쪽과 오른쪽입니다. PNG의 중심을 임의로 정렬하지 말고 각 `parts.json`에 기록된 좌표를 사용해야 합니다.

## 눈 분해 방식의 변경

가시 픽셀을 서로 겹치지 않게 나누는 방식만으로는 눈 움직임을 준비할 수 없습니다. 동공을 떼어낸 홍채와 홍채를 떼어낸 흰자에는 구멍이 남고, 눈꺼풀에 가려진 홍채의 윗부분은 원화에 존재하지 않기 때문입니다.

눈 보완본에서는 다음과 같이 겹칠 수 있는 파츠를 추가하였습니다.

- `Iris_Full`: 눈꺼풀 아래에 가려지는 부분까지 채운 원형 홍채입니다. 동공이나 반사광을 제거한 구멍이 없습니다.
- `Pupil_Full`: 홍채와 별도로 움직일 수 있는 완전한 타원형 동공입니다.
- `Catchlight_Full`, `LowerReflection_Full`: 반사광을 별도 레이어로 배치하였습니다. 아래쪽 반사광은 파란 눈에만 있습니다.
- `Sclera_Full`: 홍채 뒤와 눈꺼풀 아래까지 채운 흰자 보완 원화입니다. 기본 상태에서는 숨겨져 있습니다.
- `Sclera_Opening`: 현재 눈을 뜬 모양에 맞춘, 구멍 없는 흰자입니다. 클리핑 기준으로 사용할 수 있습니다.
- `Aperture_Guide`: 눈이 보이는 범위를 확인하는 래스터 가이드입니다. 기본 상태에서는 숨겨져 있습니다.
- `Skin_Underpaint`: 원래 눈이 있던 영역을 덮는 피부 보완 레이어입니다. 주변 원화의 피부색에 맞추어 보정하였으며, 눈 그룹과 달리 고정된 피부 그룹에 배치하였습니다. 경계의 최종 작화가 필요한 중간 자료입니다.
- 속눈썹, 위·아래 눈꺼풀 경계, 바깥 눈꼬리: 기존 원화에서 분리한 레이어입니다. 보완 원화와 달리 일부 경계의 추가 정리가 필요합니다.

보완 홍채는 원래 빨강·파랑의 배치와 단순한 셰이딩을 참고하여 새로 생성한 원화입니다. **원화의 눈과 픽셀 단위로 동일한 복원은 아니며**, 색조와 명암의 차이가 있습니다. 홍채의 상단 그림자는 현재 홍채에 포함되어 있으며, 별도의 가동 그림자 레이어로 완성한 상태는 아닙니다.

## 화질과 미리보기

가시 픽셀 분해본은 원화의 색·해상도를 변경하지 않습니다. 재조합 검사에서 가시 RGBA 불일치 픽셀은 0개였습니다. 다만 이는 잘못 배정한 픽셀, 딱딱한 마스크 경계 또는 가려진 면의 결손이 없다는 뜻은 아닙니다.

기존 작은 파츠를 최근접 보간으로 크게 표시하던 상세 미리보기를 수정하였습니다. 현재 `preview-parts.cjs`는 작은 파츠를 확대하지 않고, 실제 픽셀 크기와 표시 배율을 함께 기록합니다. 좌표 추적용 `references/` 격자 이미지는 작업용 확대 자료이므로 최종 화질 판단에 사용하지 않습니다. 전체 `contact-*.png` 시트 역시 배치 검토 자료이며, 최종 해상도 평가용이 아닙니다.

원화의 홍채는 가로 약 100픽셀입니다. 전체 이미지가 4K라는 이유만으로 작은 눈 파츠에 충분한 확대 정보가 생기는 것은 아닙니다. 새 홍채 마스터는 352 × 352이며, 전체 캐릭터와 맞추기 위한 PSD 레이어는 원래 눈 크기로 축소 배치하였습니다. 확대 편집 시에는 `eye-motion/masters/`를 사용해야 합니다. 이미지 확대만으로 손실 없는 무한 확대를 보장하지 않습니다.

생성 시트에 붙은 외부 광채는 원형·타원형의 안티앨리어싱 마스크로 제외하였습니다. 마스터는 테두리의 정상적인 1픽셀 안티앨리어싱 영역을 제외한 내부가 불투명하며, 윤곽 바깥의 광채 픽셀이 남지 않는지 검사하였습니다. 눈꺼풀 원화 자체의 계단 현상은 이 검사와 별개입니다.

## 움직임 검사와 남은 작업

눈 보완본은 정면, 좌측, 우측, 위, 아래, 동공 단독 이동 및 눈 전체 이동 두 상태의 총 여덟 상태로 이미지 합성 검사를 수행하였습니다. 시험 범위는 4K 캔버스 기준 홍채 좌우 16픽셀·상하 10픽셀, 동공 단독 이동 8픽셀, 눈 전체 이동 좌상향 (-6, -4)·우하향 (+6, +4)픽셀입니다. 완전히 열린 마스크 내부의 투명한 구멍은 검출되지 않았습니다. PSD를 다시 읽었을 때 레이어 수·좌표·RGBA가 저장 전과 일치하는 것도 확인하였습니다. 이 검사는 피부 보완의 색 이음매나 모든 눈꺼풀 경계가 완성되었다는 검사가 아닙니다.

다음 항목은 완료되지 않았습니다.

1. Cubism에서 실제 불러오기, 메시·디포머·클리핑·파라미터 연결 및 최종 동작 검사입니다.
2. 눈 뒤 피부 보완의 경계 마감과 눈꺼풀 덮개입니다. 고정 피부 레이어와 좌우 눈 그룹으로 소범위 이동을 시험하였으나, 피부와 일부 머리 경계의 미세한 이음매가 남아 있습니다. 큰 이동이나 회전에서의 품질은 검증하지 않았습니다.
3. 감은 눈 및 눈을 크게 뜬 표정, 눈꺼풀 변형용 여유분입니다.
4. 일부 눈꼬리·아래 눈꺼풀 및 속눈썹 경계의 정밀 작화입니다.
5. 머리의 기본 레이어에 남은 잔여 조각, 머리 장식에 붙은 흰 픽셀, 일부 묶음 머리의 부정확한 경계, 손가락·손톱·꽃잎 개별 분리 및 전신의 가려진 면 복원입니다.

192개 레이어 및 재조합 일치는 전체 정밀 제작 완료를 의미하지 않습니다. `qa/report.json`에는 `fineSeparationComplete: false`, `rigReady: false`를 유지하였습니다.

## Cubism 연결 시 주의사항

눈 전용 PSD는 완전한 홍채를 파괴적으로 잘라내지 않도록 PSD 클리핑·레이어 마스크 없이 저장하였습니다. 따라서 PSD의 원형 홍채가 눈꺼풀 밖으로 보일 수 있으며, 이 모습은 클리핑을 연결하기 전의 작업 원화 상태입니다.

Cubism에서 각 눈의 `Sclera_Opening`을 기준으로 같은 쪽 홍채·동공·반사광에 클리핑을 설정하고, 눈 안쪽 이동용 디포머와 눈 전체 이동용 디포머를 구분해야 합니다. 눈 깜빡임에 맞추어 흰자와 눈꺼풀의 변형도 연결해야 합니다. 실제 설정과 검증은 아직 수행하지 않았습니다. [공식 클리핑 안내](https://docs.live2d.com/en/cubism-editor-manual/clipping-mask/), [PSD 제작 주의사항](https://docs.live2d.com/en/cubism-editor-manual/precautions-for-psd-data/)를 참고할 수 있습니다.

## 재생성

설치된 `sharp`, `@napi-rs/canvas`, `ag-psd` 및 Python의 NumPy·OpenCV를 사용합니다. 새 의존성을 설치하지 않았습니다. 파생 파일을 수동 수정한 경우 재실행 전에 별도 복사본을 보존해야 합니다.

```powershell
node --max-old-space-size=8192 tools/live2d/split-visible.cjs hana-v6-precision
node tools/live2d/preview-parts.cjs Eye_
node tools/live2d/preview-parts.cjs Hair
node --max-old-space-size=8192 tools/live2d/prepare-eyes.cjs
```

이미지 생성은 재실행되지 않습니다. `eye-motion/source/`의 눈 파츠 시트와 피부 보완 텍스처를 읽어 동일한 마스크·PNG·PSD·합성 검사를 다시 만듭니다. 중간 마스크와 제외한 분해 시도는 Git에서 제외된 `.local-tools/live2d/` 아래에 보존하였습니다.
